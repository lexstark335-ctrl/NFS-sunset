# NFS sunset

基于用户拥有版权的 `rokuno-recovered-game` 驾驶场景，整合 `neon-drift` 四车车库、两份用户 GLB、红色尾灯拖尾及原创程序化合成音乐。两份源工程保留；本目录是独立的整合工程，没有 iframe、后台或在线歌单。

**功能已实现，19 项自动行为及打包测试通过。最新修复已在浏览器确认：GAME OVER 后打开车库不再被结束界面覆盖，关闭车库后恢复结束界面。其余完整验收项目仍按下文区分，Node 测试不等同于浏览器验收。**

## 运行

安装 Node.js 后，在本目录打开终端：

```powershell
node serve.cjs 4176
```

访问 **http://127.0.0.1:4176/**。服务器只监听本机，无需 `npm install`。也可以双击 `START-GAME.cmd` 启动服务器，然后复制终端中的网址。Ctrl+C 停止。

`PLAY.html` 是约 8.7 MB 的单文件版：内嵌全部模块、GLB、字体、CRT 图片和 BOOST 提示音，不使用 CDN。可以作为本地试玩文件；优先通过同一个本地 HTTP 地址访问 `/PLAY.html`，以获得稳定的浏览器存档来源。单文件的浏览器启动尚未实测。

### 连接超时处理

先在你自己的 Windows 中双击 `START-GAME.cmd`，保持终端窗口打开，用常规 Edge / Chrome 访问上述地址。工具后台显示“服务已启动”，不一定意味着内置浏览器能访问该执行环境的本机端口；本次检测到同环境 HTTP 正常、跨环境请求超时，疑似执行环境隔离，具体原因尚未确认。

若终端提示没有 Node.js，安装后重新打开启动器。若提示端口已占用，关闭此前的预览终端，或在本目录执行 `node serve.cjs 4177`，访问 `http://127.0.0.1:4177/`。不要输入 HTTPS，也不要关闭正在运行服务器的窗口。无需为本项目开放路由器端口或关闭防火墙。

## 操作与闭环

- “进入赛车”：沿用 ROKU 的进场动画、镜头和自动前进规则。
- A / D 或 ← / → 转向；W / ↑ 或原版 BOOST 按钮加速；P / Ⅱ 暂停，P / Space / RESUME 继续；ESC 或 × 退出。
- 原版入口、HUD、速度表、分数、最高分、累计分、BOOST、暂停和 GAME OVER / RETRY 保留。保留原来的落日、网格、线框山、CRT 和交通碰撞规则。
- 在入口、暂停或结束界面进入车库。四张车型卡包含真实模型预览、速度 / 转向 / BOOST 参数、作者、选车和免费试驾。选车会更换主驾驶场景的真实模型。
- 解锁规则沿用 ROKU：ION 免费，VECTOR 累计 3,000，IGNITION 累计 10,000，PATROL 累计 30,000。达到阈值后解锁，不扣累计分。
- 免费试驾可驾驶锁定车型。试驾结算不累计分、不改最高分，不写选车/解锁存档。试驾中重试仍为试驾；退出或重新进入车库时恢复正常车型。
- 原版蓝白色 BOOST 光片、尾部光带已禁用，BOOST 仍改变速度和视野。新红色尾迹随速度增长，低速消失；统一参与 Bloom，背景和道路没有历史残影。

## 音乐

右侧 FM 面板的“音乐 ▷”首次点击后才创建并启动合成器。支持播放/暂停、音量、静音；引擎和提示音有独立开关，默认关闭。

原创 **NIGHT CIRCUIT**，110 BPM，32 小节结构，含八小节和声、四种编排段落、深沉贝斯、交替琶音、立体声 Pad、旋律、底鼓/军鼓/踩镲。短延迟、低通滤波与压缩器控制高频和峰值。BOOST 平滑增加滤波亮度，不重置节拍；游戏暂停时音乐降至原音量的 25%，恢复后渐升。高频和响度的实际听感仍需设备实测。

音乐、引擎共用一个延迟创建的 AudioContext；每个音符结束后断开节点。原恢复版旧歌单播放器已移除；原版频谱柱读取新音乐的同一个分析器。

## 存档

按本次要求**不迁移旧存档**。新前缀 `roku-neon-integrated-v1-`，保存累计分、最高分、已解锁车型和当前正常车型。不会读写两个源工程的旧前缀。分数仍在正常碰撞结算时保存；直接退出未结束的一局不结算，沿用原版规则。

存档属于浏览器及网址来源；换浏览器、换端口或在文件与 HTTP 入口之间切换，可能看到不同存档。存储被禁用时仍可玩，但无法持久保存。音频开关不自动恢复为播放状态。

## 代码与重建

```powershell
node scripts/validate.cjs
```

该命令重新生成整合场景、入口与单文件，检查语法并运行所有测试，写出 `validation.json` 和 `verification/node-tests.tap`。

| 位置 | 职责 |
|---|---|
| `vendor/roku-scene.original.js` | 恢复版场景的原样副本，作为适配基线 |
| `scripts/integrate.cjs` | 带唯一匹配断言的原版适配：车型、试驾、存档、分层、音乐接口 |
| `assets/sceneApp-7cpBE01P.js` | 生成的主场景，保留原驾驶和镜头 |
| `src/runtime.js` | 单一场景桥接、输入控件与逐帧表现更新 |
| `src/three.js` | 原版 Three.js r184 导出别名；所有新增模块共用同一库 |
| `src/models.js` | 四车模型、GLB 归一化、自发光材质与尾灯锚点 |
| `src/garage.js` | 车型卡、选车/试驾、一个按需渲染的预览器 |
| `src/trails.js` / `trail-state.js` | 分层通道、双灯历史、速度映射与柔边红色尾迹 |
| `src/music.js` | 原创曲谱、Web Audio 调度、滤波、包络和节点释放 |
| `scripts/page.cjs` / `recovery.css` | 保留 HUD 的页面拼装、车库与 FM 样式 |
| `build-single.cjs` | 本地资源和 ESM import map 内嵌打包 |
| `tests/` | 原驾驶核心、试驾存档、车库对象、音频生命周期、拖尾与资源闭合测试 |

主游戏只启动原场景的一套模拟循环、主 WebGLRenderer 和 EffectComposer。三层 RenderPass 依次绘制世界、车、红尾迹，保留深度后共用原版 UnrealBloomPass / CRT。车库另有一个预览 renderer，首次打开时创建，缓存四辆车，每次开库/选车只绘制四张图；关闭车库无预览 RAF。旧车库预览代码不再被调用。

恢复版核心仍是原发布构建的压缩代码，未声称还原了原作者源码。修改驾驶适配请改 `scripts/integrate.cjs`，不要只改生成文件，否则重建会覆盖。新模块都有中文职责注释。

## 验证边界

已完成 **19 项自动测试**：真实 GLB 几何解析；四车型对象切换；原版进场/转向/BOOST/暂停；真实交通碰撞路径；重试；解锁与新实例读取存档；四车试驾隔离；尾迹几何及分层；25 次开关车库的对象复用；音乐长时调度和节点结束释放；反复播放、静音、引擎切换；所有本地及单文件资源闭合。

这些测试执行真实 Three.js 数学/几何、原模拟函数与新增模块，但使用最小 DOM、模拟 GPU 和模拟 AudioContext；GLB 纹理像素未解码。新实例读取存储替身不等于浏览器刷新实测，缓存对象复用不等于 GPU 内存实测。

首次交付时本机 HTTP 服务返回 200，但自动化浏览器连接超时。2026-11-05 的后续修复中，浏览器已能访问页面，并实际确认 GAME OVER → 打开车库 → 关闭车库的遮罩行为。真实截图见 `verification/garage-overlay-fixed.jpg`，记录见 `verification/garage-overlay-fix.md`。该次验证未覆盖完整驾驶、音频听感、控制台、刷新存档和显卡内存走势；详细待验项目见 `verification/MANUAL-CHECKS.md`。
